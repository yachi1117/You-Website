# 管理后台使用指南

## 概述

管理后台允许管理员通过直观的 Web 界面管理博客文章，无需编辑代码。支持创建、编辑、删除文章，以及实时预览 Markdown 内容。

## 访问管理后台

### 1. 启动开发服务器

```bash
# 启动前端开发服务器
npm start

# 在另一个终端启动 Worker（如果还没启动）
cd cloudflare-worker
npm run dev
```

### 2. 访问登录页面

在浏览器中打开：`http://localhost:3000/admin`

### 3. 登录

使用配置的密码登录（默认：`your-secret-token`）

**配置密码**：
- 开发环境：在 `.env` 文件中设置 `REACT_APP_ADMIN_TOKEN`
- 生产环境：在 Cloudflare Dashboard 中设置环境变量

## 功能说明

### 文章列表页面 (`/admin/blog`)

**功能**：
- 查看所有文章
- 显示文章的基本信息（标题、日期、标签等）
- 编辑文章
- 删除文章
- 创建新文章

**操作**：
- 点击 **"+ 新建文章"** 按钮创建新文章
- 点击 **"编辑"** 按钮编辑文章
- 点击 **"删除"** 按钮删除文章（需要确认）

### 文章编辑页面 (`/admin/blog/:id` 或 `/admin/blog/new`)

#### 基本信息

- **Slug**（必填）：URL 友好的标识符，用于文章 URL
  - 可以手动输入
  - 可以点击"从标题生成"自动生成
- **发布日期**（必填）：文章的发布日期
- **标题**（必填）：文章主标题
- **副标题**（可选）：文章副标题

#### 媒体管理

- **封面图片**：设置文章封面图片 URL
  - 支持预览
- **图片库**：管理文章中的图片
  - 添加图片路径和说明
  - 可以添加多张图片
  - 支持删除图片

#### 标签管理

- 添加标签：输入标签后按回车或点击"添加"
- 删除标签：点击标签旁边的 × 按钮
- 标签用于文章分类和筛选

#### Markdown 编辑器

**左侧：编辑器**
- 输入 Markdown 格式的内容
- 支持语法高亮
- 实时保存（手动保存）

**右侧：实时预览**
- 实时显示 Markdown 转换后的 HTML
- 所见即所得

**支持的 Markdown 语法**：
- 标题：`# H1`, `## H2`, `### H3`
- 粗体：`**文本**`
- 斜体：`*文本*`
- 图片：`![说明](路径)`
- 链接：`[文本](URL)`
- 代码：`` `代码` `` 和 ` ```代码块``` ``
- 引用：`> 引用文本`
- 列表：`- 项目` 和 `1. 项目`

**自定义语法**：
- 视频：使用 `:::video` 语法
  ```markdown
  :::video
  /images/video.mov
  :::
  ```

#### 保存文章

- 点击 **"保存更改"** 或 **"创建文章"** 按钮
- 系统会验证必填字段
- 保存成功后显示成功消息
- 新建文章保存后会自动跳转到编辑页面

## 环境变量配置

### 开发环境

创建 `.env` 文件（在项目根目录）：

```env
REACT_APP_API_URL=http://localhost:8787
REACT_APP_ADMIN_TOKEN=your-secret-token-here
```

### 生产环境

在 Cloudflare Dashboard 中设置：
1. 进入 Workers & Pages
2. 选择你的 Worker
3. Settings > Variables
4. 添加：
   - `ADMIN_TOKEN`: 你的管理密码

在前端部署时，设置环境变量：
- `REACT_APP_API_URL`: 你的 Worker URL
- `REACT_APP_ADMIN_TOKEN`: 与 Worker 中的 `ADMIN_TOKEN` 相同

## 使用流程示例

### 创建新文章

1. 访问 `/admin/blog`
2. 点击 **"+ 新建文章"**
3. 填写基本信息：
   - 输入标题
   - 点击"从标题生成"生成 slug
   - 选择发布日期
4. 添加封面图片（可选）
5. 添加图片到图片库（可选）
6. 添加标签（可选）
7. 在 Markdown 编辑器中输入正文
8. 在右侧预览区域查看效果
9. 点击 **"创建文章"** 保存

### 编辑现有文章

1. 访问 `/admin/blog`
2. 找到要编辑的文章
3. 点击 **"编辑"** 按钮
4. 修改需要更新的内容
5. 点击 **"保存更改"** 保存

### 删除文章

1. 访问 `/admin/blog`
2. 找到要删除的文章
3. 点击 **"删除"** 按钮
4. 确认删除操作
5. 文章将被永久删除

## 注意事项

### 1. 认证安全

- 当前使用简单的密码认证
- 生产环境建议使用更安全的方案：
  - Cloudflare Access
  - OAuth 登录
  - JWT Token

### 2. 数据备份

- 删除操作不可撤销
- 建议定期备份数据库
- 重要内容建议先在本地保存

### 3. Markdown 格式

- 确保 Markdown 语法正确
- 图片路径使用相对路径（如 `/images/photo.jpg`）
- 视频使用自定义 `:::video` 语法

### 4. Slug 唯一性

- Slug 必须唯一
- 如果 slug 已存在，创建会失败
- 编辑时不能修改 slug

## 故障排除

### 无法登录

- 检查 `.env` 文件中的 `REACT_APP_ADMIN_TOKEN` 是否正确
- 检查 Worker 是否正在运行
- 检查浏览器控制台是否有错误

### 无法保存文章

- 检查是否填写了所有必填字段
- 检查网络连接
- 检查 Worker API 是否正常
- 查看浏览器控制台的错误信息

### Markdown 预览不正确

- 检查 Markdown 语法是否正确
- 某些复杂语法可能不支持
- 查看浏览器控制台是否有错误

### 图片不显示

- 检查图片路径是否正确
- 确保图片文件存在于指定路径
- 检查图片 URL 是否可访问
